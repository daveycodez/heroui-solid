# Dropdown

A dropdown displays a list of actions or options that a user can choose

## Import

```tsx
import { Dropdown } from "heroui-solid";
```

## Usage

Actions are plain `Dropdown.Item`s with an `onSelect` handler. Use the
standalone `Label` (and `Description`) components for the item text — HeroUI has
no dropdown-specific label part.

### Anatomy

Import the Dropdown component and access all parts using dot notation. The menu
is portalled, so it is wrapped in `Dropdown.Portal`.

```tsx
import { Dropdown, Label, Description, Separator } from "heroui-solid";

export default () => (
  <Dropdown>
    <Dropdown.Trigger />
    <Dropdown.Portal>
      <Dropdown.Popover>
        <Dropdown.Menu>
          <Dropdown.Item>
            <Label />
            <Description />
          </Dropdown.Item>
          <Separator />
          <Dropdown.Group>
            <Dropdown.GroupLabel />
            <Dropdown.Item />
          </Dropdown.Group>
          <Dropdown.RadioGroup>
            <Dropdown.RadioItem value="a">
              <Dropdown.ItemIndicator />
              <Label />
            </Dropdown.RadioItem>
          </Dropdown.RadioGroup>
          <Dropdown.CheckboxItem>
            <Dropdown.ItemIndicator />
            <Label />
          </Dropdown.CheckboxItem>
          <Dropdown.Sub>
            <Dropdown.SubTrigger>
              <Label />
            </Dropdown.SubTrigger>
            <Dropdown.Portal>
              <Dropdown.SubContent>
                <Dropdown.Menu>
                  <Dropdown.Item />
                </Dropdown.Menu>
              </Dropdown.SubContent>
            </Dropdown.Portal>
          </Dropdown.Sub>
        </Dropdown.Menu>
      </Dropdown.Popover>
    </Dropdown.Portal>
  </Dropdown>
);
```

## API Reference

### Dropdown Props

| Prop            | Type                      | Default          | Description                                        |
| --------------- | ------------------------- | ---------------- | -------------------------------------------------- |
| `open`          | `boolean`                 | -                | The controlled open state of the menu              |
| `defaultOpen`   | `boolean`                 | -                | The initial open state (uncontrolled)              |
| `onOpenChange`  | `(open: boolean) => void` | -                | Handler called when the open state changes         |
| `placement`     | `Placement`               | `"bottom-start"` | Placement of the menu relative to the trigger      |
| `gutter`        | `number`                  | `8`              | Distance in px between the trigger and the content |
| `shift`         | `number`                  | `0`              | Offset along the trigger, in px                    |
| `modal`         | `boolean`                 | `true`           | Whether the menu is modal (traps focus/scroll)     |
| `preventScroll` | `boolean`                 | `true`           | Whether page scroll is blocked while open          |
| `children`      | `JSX.Element`             | -                | The trigger, portal, and content                   |

*Plus Kobalte Popper positioning props (`flip`, `slide`, `overlap`, `arrowPadding`, …).*

### Dropdown.Trigger Props

| Prop       | Type             | Default  | Description                                                       |
| ---------- | ---------------- | -------- | ---------------------------------------------------------------- |
| `as`       | `ValidComponent` | `Button` | Rendered element — defaults to our `Button` (Kobalte polymorphic) |
| `class`    | `string`         | -        | Additional CSS classes                                           |
| `children` | `JSX.Element`    | -        | Trigger content                                                  |

*Plus `Button` props (`variant`, `isIconOnly`, …) when using the default trigger, or standard `<button>` attributes.*

### Dropdown.Portal Props

| Prop       | Type          | Default | Description                    |
| ---------- | ------------- | ------- | ------------------------------ |
| `mount`    | `Node`        | `body`  | Where the content is portalled |
| `children` | `JSX.Element` | -       | The `Dropdown.Popover`         |

### Dropdown.Popover Props

The scroll container — the popover styling (max-height, overflow, background,
shadow) lives here. It wraps a `Dropdown.Menu`.

| Prop                   | Type                             | Default | Description                                          |
| ---------------------- | -------------------------------- | ------- | ---------------------------------------------------- |
| `as`                   | `ValidComponent`                 | `"div"` | Overrides the rendered element (Kobalte polymorphic) |
| `onEscapeKeyDown`      | `(event: KeyboardEvent) => void` | -       | Handler called when the escape key is pressed        |
| `onPointerDownOutside` | `(event: PointerEvent) => void`  | -       | Handler called on a pointer down outside the content |
| `class`                | `string`                         | -       | Additional CSS classes                               |
| `children`             | `JSX.Element`                    | -       | The `Dropdown.Menu`                                  |

*Plus standard `<div>` attributes.*

### Dropdown.Menu Props

The padded item list inside a `Dropdown.Popover` (or `Dropdown.SubContent`).
Items, groups, separators and submenus go here.

| Prop       | Type          | Default | Description                              |
| ---------- | ------------- | ------- | ---------------------------------------- |
| `class`    | `string`      | -       | Additional CSS classes                   |
| `children` | `JSX.Element` | -       | Menu items, groups, separators, submenus |

*Plus standard `<div>` attributes.*

### Dropdown.Item Props

| Prop            | Type                    | Default     | Description                                          |
| --------------- | ----------------------- | ----------- | ---------------------------------------------------- |
| `as`            | `ValidComponent`        | `"div"`     | Overrides the rendered element (Kobalte polymorphic) |
| `variant`       | `"default" \| "danger"` | `"default"` | Visual variant of the item                           |
| `onSelect`      | `() => void`            | -           | Handler called when the item is activated            |
| `disabled`      | `boolean`               | `false`     | Whether the item is disabled                         |
| `closeOnSelect` | `boolean`               | `true`      | Whether the menu closes when the item is activated   |
| `textValue`     | `string`                | -           | Text used for typeahead                              |
| `class`         | `string`                | -           | Additional CSS classes                               |

*Plus standard `<div>` attributes.*

### Item text — `Label` / `Description`

Item text and secondary text use the standalone `Label` and `Description`
components — HeroUI has no dropdown-specific label part. They stamp the
`data-slot="label"`/`data-slot="description"` hooks the item styling targets.

### Dropdown.ItemIndicator Props

| Prop         | Type             | Default | Description                                            |
| ------------ | ---------------- | ------- | ------------------------------------------------------ |
| `as`         | `ValidComponent` | `"div"` | Overrides the rendered element (Kobalte polymorphic)   |
| `forceMount` | `boolean`        | `false` | Render even when the item is not checked               |
| `class`      | `string`         | -       | Additional CSS classes                                 |
| `children`   | `JSX.Element`    | -       | Indicator content (rendered when the item is checked)  |

### Dropdown.CheckboxItem Props

| Prop             | Type                         | Default     | Description                                       |
| ---------------- | ---------------------------- | ----------- | ------------------------------------------------- |
| `as`             | `ValidComponent`             | `"div"`     | Overrides the rendered element                    |
| `variant`        | `"default" \| "danger"`      | `"default"` | Visual variant of the item                        |
| `checked`        | `boolean`                    | -           | The controlled checked state                      |
| `defaultChecked` | `boolean`                    | -           | The initial checked state (uncontrolled)          |
| `onChange`       | `(checked: boolean) => void` | -           | Handler called when the checked state changes     |
| `disabled`       | `boolean`                    | `false`     | Whether the item is disabled                      |
| `closeOnSelect`  | `boolean`                    | `false`     | Whether the menu closes when the item is toggled  |

*Plus standard `<div>` attributes.*

### Dropdown.RadioGroup Props

| Prop           | Type                      | Default | Description                               |
| -------------- | ------------------------- | ------- | ----------------------------------------- |
| `value`        | `string`                  | -       | The controlled selected value             |
| `defaultValue` | `string`                  | -       | The initial selected value (uncontrolled) |
| `onChange`     | `(value: string) => void` | -       | Handler called when the value changes     |

### Dropdown.RadioItem Props

| Prop            | Type                    | Default     | Description                                       |
| --------------- | ----------------------- | ----------- | ------------------------------------------------- |
| `as`            | `ValidComponent`        | `"div"`     | Overrides the rendered element                    |
| `value`         | `string`                | -           | The value of this radio item (required)           |
| `variant`       | `"default" \| "danger"` | `"default"` | Visual variant of the item                        |
| `disabled`      | `boolean`               | `false`     | Whether the item is disabled                      |
| `closeOnSelect` | `boolean`               | `true`      | Whether the menu closes when the item is selected |

*Plus standard `<div>` attributes.*

### Dropdown.Group / Dropdown.GroupLabel Props

`Dropdown.Group` groups a set of items into a section; label it with
`Dropdown.GroupLabel`. `GroupLabel` registers its id with the group so Kobalte
stamps `aria-labelledby` on the section (the same wiring React Aria gives
HeroUI's `<Header>`). It renders **as** our `Header` by default, so it keeps the
header styling — pass `as` to override.

| Prop       | Type             | Default            | Description                                          |
| ---------- | ---------------- | ------------------ | ---------------------------------------------------- |
| `as`       | `ValidComponent` | `"div"` / `Header` | Overrides the rendered element (Group / GroupLabel)  |
| `class`    | `string`         | -                  | Additional CSS classes                               |
| `children` | `JSX.Element`    | -                  | The `GroupLabel` and items / label content           |

Separate groups with the standalone `Separator` component.

### Dropdown.Sub / Dropdown.SubTrigger / Dropdown.SubContent Props

`Dropdown.Sub` accepts the same positioning props as the root (including the
`gutter` default of `8`). `Dropdown.SubTrigger` takes the same props as
`Dropdown.Item` (`variant`, `disabled`, `textValue`, …), and
`Dropdown.SubContent` the same props as `Dropdown.Popover` — it also wraps a
`Dropdown.Menu`.

### Dropdown.Arrow Props

| Prop   | Type     | Default | Description                  |
| ------ | -------- | ------- | ---------------------------- |
| `size` | `number` | `30`    | The size of the arrow, in px |

## Rendered Elements

Every part is polymorphic — pass `as` to override the element. The `Dropdown`
root, `Dropdown.Portal`, `Dropdown.Sub`, and `Dropdown.RadioGroup` render no
element of their own.

| Component                  | Default Element |
| -------------------------- | --------------- |
| `Dropdown.Trigger`         | `<button>`      |
| `Dropdown.Popover`         | `<div>`         |
| `Dropdown.Menu`            | `<div>`         |
| `Dropdown.Item`            | `<div>`         |
| `Dropdown.ItemIndicator`   | `<div>`         |
| `Dropdown.CheckboxItem`    | `<div>`         |
| `Dropdown.RadioItem`       | `<div>`         |
| `Dropdown.Group`           | `<div>`         |
| `Dropdown.GroupLabel`      | `<header>`      |
| `Dropdown.SubTrigger`      | `<div>`         |
| `Dropdown.SubContent`      | `<div>`         |

## Differences from HeroUI React

This port is a thin skin over Kobalte's `DropdownMenu`, so the API is Kobalte's,
not HeroUI React's:

- **Structure.** Like HeroUI React, `Dropdown.Popover` (the scroll container)
  wraps `Dropdown.Menu` (the padded item list) which holds the items — kept as
  two elements so the popover can scroll while item focus rings aren't clipped.
  The popover is wrapped in an optional `Dropdown.Portal`. (Kobalte's `role="menu"`
  lives on the popover element; `Dropdown.Menu` stays presentational.)
- **Trigger.** `Dropdown.Trigger` renders our `Button` by default, so
  `<Dropdown.Trigger variant="secondary">` just works — no need to nest a
  `<Button>` as the first child of `Dropdown`. Pass `as` (e.g. `as="button"`) to
  render a different element.
- **Selection.** There is no `selectionMode`/`selectedKeys` on the menu. Use
  `Dropdown.RadioGroup` + `Dropdown.RadioItem` for single selection and
  `Dropdown.CheckboxItem` for multiple selection, each controlled with its own
  `value`/`checked` + `onChange`.
- **Item text.** Use the standalone `Label`/`Description` components (there is no
  `Dropdown.Label`), placed inside the item.
- **Sections.** Use `Dropdown.Group` + `Dropdown.GroupLabel` for the section and
  its label, separated by the standalone `Separator` (there is no
  `Dropdown.Separator`). `Dropdown.GroupLabel` renders as HeroUI's `Header` and,
  like React Aria's `<Header>`, registers with the group so it auto-wires
  `aria-labelledby`.
- **Disabled items.** Set `disabled` per item, not `disabledKeys` on the menu.
- **Submenu indicator.** There is no `Dropdown.SubmenuIndicator` — place any icon
  inside `Dropdown.SubTrigger`.
- **Item selection.** `onSelect` on `Dropdown.Item` takes no key argument (it is
  scoped to the item); there is no menu-level `onAction`.
- **Long-press trigger.** Kobalte has no long-press trigger, so HeroUI React's
  "Long Press Trigger" example has no equivalent here.
- **Styling only.** This skin applies HeroUI's variant classes; open/close
  animations and the CSS state bridges are not wired up yet.
