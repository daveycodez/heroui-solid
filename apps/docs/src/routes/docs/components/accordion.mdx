# Accordion

A collapsible content panel for organizing information in a compact space

## Import

```tsx
import { Accordion } from "heroui-solid";
```

### Anatomy

Import the Accordion component and access all parts using dot notation.zz

```tsx
import { Accordion } from "heroui-solid";

export default () => (
  <Accordion>
    <Accordion.Item>
      <Accordion.Header>
        <Accordion.Trigger />
      </Accordion.Header>
      <Accordion.Content />
    </Accordion.Item>
  </Accordion>
);
```
