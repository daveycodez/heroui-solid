# Accordion

A collapsible content panel for organizing information in a compact space

## Import

```tsx
import { Accordion } from "heroui-solid";
```

### Anatomy

Import the Accordion component and access all parts using dot notation.

```tsx
import { Accordion } from "heroui-solid";

export default () => (
  <Accordion>
    <Accordion.Item>
      <Accordion.Header>
        <Accordion.Trigger />
      </Accordion.Header>
      <Accordion.Content />
    </Accordion.Item>
  </Accordion>
);
```

## Styling

### Passing Tailwind CSS classes

```tsx
import { Accordion, cn } from "heroui-solid";

function CustomAccordion() {
  return (
    <Accordion class="bg-surface-1/10 w-full max-w-md rounded-2xl" variant="surface">
      <Accordion.Item value="item" class={cn("group/item", "first:[&_[data-slot=accordion-trigger]]:rounded-t-2xl")}>
        ...
      </Accordion.Item>
    </Accordion>
  );
}
```

### Customizing the component classes

To customize the Accordion component classes, you can use the `@layer components` directive.
[Learn more](https://tailwindcss.com/docs/adding-custom-styles#adding-component-classes).

```css
@layer components {
  .accordion {
    @apply rounded-xl bg-gray-50;
  }

  .accordion__trigger {
    @apply font-semibold text-lg;
  }

  .accordion--outline {
    @apply shadow-lg border-2;
  }
}
```

HeroUI follows the [BEM](https://getbem.com/) methodology to ensure component variants and states are reusable and easy to customize.

### CSS Classes

The Accordion component uses these CSS classes ([View source styles](https://github.com/heroui-inc/heroui/blob/v3/packages/styles/components/accordion.css)):

#### Base Classes

- `.accordion` - Base accordion container
- `.accordion__body` - Content body container
- `.accordion__body-inner` - Content body padding wrapper
- `.accordion__heading` - Heading wrapper
- `.accordion__indicator` - Expand/collapse indicator icon
- `.accordion__item` - Individual accordion item
- `.accordion__panel` - Collapsible panel container
- `.accordion__trigger` - Clickable trigger button

#### Variant Classes

- `.accordion--surface` - Surface variant with background and rounded corners

#### State Classes

- `.accordion__trigger[aria-expanded="true"]` - Expanded state
- `.accordion__panel[data-expanded]` - Panel visible state

### Interactive States

The component supports both CSS pseudo-classes and data attributes for flexibility:

- **Hover**: `:hover` on trigger
- **Focus**: `:focus-visible` on trigger
- **Disabled**: `:disabled` or `[aria-disabled="true"]` on trigger
- **Expanded**: `[aria-expanded="true"]` on trigger

## API Reference

### Accordion Props

| Prop              | Type                        | Default     | Description                                                  |
| ----------------- | --------------------------- | ----------- | ------------------------------------------------------------ |
| `variant`         | `"default" \| "surface"`    | `"default"` | The visual variant of the accordion                          |
| `hideSeparator`   | `boolean`                   | `false`     | Hide the separator line between items                        |
| `value`           | `string[]`                  | -           | The controlled expanded item values                          |
| `defaultValue`    | `string[]`                  | -           | The initial expanded item values (uncontrolled)              |
| `onChange`        | `(value: string[]) => void` | -           | Handler called when the expanded values change               |
| `multiple`        | `boolean`                   | `false`     | Whether multiple items can be expanded at once               |
| `collapsible`     | `boolean`                   | `false`     | Whether the open item can be collapsed in single mode        |
| `shouldFocusWrap` | `boolean`                   | `true`      | Whether keyboard focus wraps around at the start/end         |
| `as`              | `ValidComponent`            | `"div"`     | Overrides the rendered element (Kobalte polymorphic).        |
| `class`           | `string`                    | -           | Additional CSS classes                                       |
| `children`        | `JSX.Element`               | -           | The accordion items                                          |

*Plus standard `<div>` attributes.*

### Accordion.Item Props

| Prop         | Type             | Default | Description                                                  |
| ------------ | ---------------- | ------- | ------------------------------------------------------------ |
| `value`      | `string`         | -       | A unique value for the item (required)                       |
| `disabled`   | `boolean`        | `false` | Whether this item is disabled                                |
| `forceMount` | `boolean`        | `false` | Force mounting the item content (for animation control)      |
| `as`         | `ValidComponent` | `"div"` | Overrides the rendered element (Kobalte polymorphic).        |
| `class`      | `string`         | -       | Additional CSS classes                                       |
| `children`   | `JSX.Element`    | -       | The item content                                             |

*Plus standard `<div>` attributes.*

### Accordion.Header Props

| Prop       | Type             | Default | Description                                                  |
| ---------- | ---------------- | ------- | ------------------------------------------------------------ |
| `as`       | `ValidComponent` | `"h3"`  | Overrides the rendered element (Kobalte polymorphic).        |
| `class`    | `string`         | -       | Additional CSS classes                                       |
| `children` | `JSX.Element`    | -       | The heading content (usually a `Accordion.Trigger`)          |

### Accordion.Trigger Props

| `children` | `JSX.Element`    | -          | Trigger content                                              |

*Plus standard `<button>` attributes.*

### Accordion.Content Props

| Prop       | Type             | Default | Description                                                  |
| ---------- | ---------------- | ------- | ------------------------------------------------------------ |
| `as`       | `ValidComponent` | `"div"` | Overrides the rendered element (Kobalte polymorphic).        |
| `class`    | `string`         | -       | Additional CSS classes                                       |
| `children` | `JSX.Element`    | -       | Panel content                                                |

*Plus standard `<div>` attributes.*

### Accordion.Indicator Props

`Accordion.Indicator` is a HeroUI add-on with no Kobalte equivalent. It renders a
plain `<span>` (not polymorphic, so no `as`).

| Prop       | Type          | Default | Description                                             |
| ---------- | ------------- | ------- | ------------------------------------------------------ |
| `class`    | `string`      | -       | Additional CSS classes                                 |
| `children` | `JSX.Element` | -       | Custom indicator icon (defaults to a rotating chevron) |

*Plus standard `<span>` attributes.*

## Rendered Elements

Every part except `Accordion.Indicator` is polymorphic — pass `as` to override
its element.

| Component              | Default Element |
| ---------------------- | --------------- |
| `Accordion`            | `<div>`         |
| `Accordion.Item`       | `<div>`         |
| `Accordion.Header`     | `<h3>`          |
| `Accordion.Trigger`    | `<button>`      |
| `Accordion.Content`    | `<div>`         |
| `Accordion.Indicator`  | `<span>`        |

## Differences from HeroUI React

- Expanded state uses Kobalte's `value`/`defaultValue`/`onChange` (arrays of
  string values) instead of React Aria's `expandedKeys`/`onExpandedChange`
  (a `Set` of keys), and each `Accordion.Item` takes a `value` rather than an
  `id`.
- `multiple` replaces `allowsMultipleExpanded`, and `collapsible` controls
  whether the open item can be closed in single-expand mode.
- Disabling is per-item via `disabled` (Kobalte) — there is no root-level
  `isDisabled`.
- Compound parts follow Kobalte: `Accordion.Header` and `Accordion.Content`
  (not `Accordion.Heading`/`Accordion.Panel`). There is no separate
  `Accordion.Body` — put content directly in `Accordion.Content`, which carries
  the body padding itself.
- Polymorphism uses Kobalte's `as` prop instead of React's `render` prop.
- `Accordion.Indicator` renders a default chevron and rotates via CSS; pass
  children to customize the icon.
